# AI Fact Check Agent

An AI-powered web application that verifies factual claims from PDFs using live web evidence.

## Features
- Upload PDF documents
- Extract factual claims
- Verify claims using AI + web search
- Detect false and inaccurate information
- View evidence sources

## Tech Stack
- Streamlit
- OpenRouter
- Tavily API
- Python
- PyMuPDF

## How It Works
1. Upload PDF
2. Extract claims
3. Search web
4. Verify claims
5. Display results

## Run Locally

pip install -r requirements.txt

streamlit run app.py
